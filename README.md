\# 🎙️ Speech Emotion Recognition



\## 📌 Project Overview



Speech Emotion Recognition is a machine learning application that identifies human emotions from speech audio.



The system extracts MFCC (Mel-Frequency Cepstral Coefficients) features from speech signals and uses a neural network classifier to predict the speaker's emotion.



This project was developed as part of the CodeAlpha Machine Learning Internship.



\## 🎯 Objectives



\- Detect emotions from speech audio.

\- Extract useful audio features using MFCC.

\- Train a machine learning model.

\- Evaluate model performance.

\- Provide an interactive web application using Streamlit.



\## 😊 Supported Emotions



The model recognizes eight emotions:



\- Neutral

\- Calm

\- Happy

\- Sad

\- Angry

\- Fearful

\- Disgust

\- Surprised
